Panduan Cara Instalasi di HP Android

1

Klik Tombol Unduh

Tekan tombol "Unduh APK Sekarang" di atas. File guberstudio.apk akan mulai diunduh ke perangkat Anda.

2

Peringatan "File Mungkin Berbahaya"

Jika browser Chrome/Android menampilkan peringatan karena file APK diunduh langsung dari web (bukan Play Store), pilih "Tetap Download" (Download anyway).

3

Izinkan Sumber Tidak Dikenal

Buka file hasil unduhan di panel notifikasi atau folder Download. Jika diminta perizinan, aktifkan "Izinkan dari sumber ini" (Allow from this source) di menu Pengaturan Keamanan.

4

Selesai & Jalankan

Tekan Install. Setelah selesai, buka aplikasi GuberStudio dan nikmati fitur-fiturnya!
